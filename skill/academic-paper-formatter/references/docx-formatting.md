# DOCX 排版说明

`python-docx` 可读取和设置段落、文本片段、表格、节、页眉和页脚的大部分属性。部分 Word 属性（包括东亚字体名称）存储在 OOXML 中，项目脚本会在需要时直接设置这些属性。

提取出的规则 JSON 区分模板中观察到的值和待复核的推断信息，主要包含：

- `source`：模板文件名与提取器版本。
- `page`：首个节的页面尺寸和页边距；各节不一致时会产生警告。
- `role_rules`：映射到语义角色的样式规则。
- `table_rules`、`figure_rules`、`reference_rules`：从模板观察到或保守推断的规则，应在使用前审阅。
- `extraction_warnings`：需要人工确认的问题。

模板定义了命名样式时优先复用这些样式。若文档主要依赖直接格式，提取器会采样最常见的格式，并标记为待审阅。底层样式互相冲突时，不要只凭渲染后的外观判断规则。

浮动图片以 OOXML `wp:anchor` 元素保存。图片规范工具仅调整锚点位置与重叠标志，不会栅格化、替换或裁切图片，也不移动题注。目录与交叉引用属于动态 Word 字段；设置 `w:updateFields` 只是请求 Word 打开文件时刷新字段。字段刷新后，仍须重新渲染并检查版面。
