# 中国学位论文格式原则

学校或期刊的正式模板优先于所有通用习惯。中文学位论文常见封面、中英文摘要、目录、章节标题、图表、参考文献、致谢和附录，但各院校对这些部分的名称、顺序、格式和是否必需存在实质差异。

开始处理国内学位论文时，先确认学位层级。本科论文常见中英文摘要与关键词、目录、参考文献、致谢和附录；硕士与博士论文可能还包含原创性声明、授权书或攻读学位期间成果页。这些仅用于人工复核，不是通用强制规范。具体组成、命名、顺序、页码与格式均由学校模板和书面指南决定。

如果模板没有显示某个组成部分，应将其规则留空并记录提取警告。向用户索取书面指南或明确确认，不要猜测。

生成的 JSON 记录模板中的观察样式与角色映射，不含学校名称，可与论文项目一起保存为可追溯的格式配置。
